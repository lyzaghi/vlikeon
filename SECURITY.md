# Security policy

## Support status

Vlikeon Browser is pre-release source. No version is designated as a supported,
security-qualified release. Runtime, sandbox, updater and synchronization source
have not completed verification. Do not rely on them for production protection.

## Report a vulnerability

After publication, use GitHub's **Report a vulnerability** only if private
vulnerability reporting is visibly enabled for this repository. This file alone
does not enable that feature.

If no private channel is available, open a minimal issue asking the maintainer
for a private contact route. Do not include exploitation details, credentials,
personal data or public proof of concept in that request. A dedicated security
email address has not yet been published.

In a private report, include the affected revision, component, impact,
synthetic reproduction and whether the finding was reproduced or found by
source review. No fixed response SLA or bounty is currently promised.

Relevant areas include browser/native capabilities, containment, file grants,
saves, updates, authentication and sync. Report upstream defects to the relevant
project through its disclosure process as appropriate.
