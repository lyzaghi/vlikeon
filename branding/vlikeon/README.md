# Vlikeon brand assets

Vlikeon Browser is the gaming browser project by Vlike. Its **Open View** mark
uses an open frame and a central negative-space V, with cyan, violet and magenta
outlines. The GitHub presentation keeps the existing mark geometry.

| Use | Location |
| --- | --- |
| Transparent vector masters | [`svg/`](svg/) |
| Raster exports and display variants | [`png/`](png/) |
| Repository and profile banner | [`github/banner.svg`](github/banner.svg) |
| Web icons and favicon | [`web/`](web/) |
| Windows icons | [`windows/`](windows/) |
| Apple foreground assets | [`apple/`](apple/) |
| macOS icon set | [`macos/`](macos/) |
| Linux desktop icons | [`linux/`](linux/) |

Use the light-background variant where the neon or white mark lacks contrast.
Keep the mark's proportions and open interior; do not stretch or fill its frame.
The GitHub banner has an intentional dark background and is a presentation asset,
not a transparent application icon or a product screenshot.

See [export notes](EXPORT_NOTES.md), [verification inventory](ASSET_VERIFICATION.json)
and the [original Vietnamese guide](BRAND.vi.md) for asset history and details.
Icon exports do not establish platform installation or store acceptance.
