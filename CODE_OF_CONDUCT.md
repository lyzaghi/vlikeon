# Community conduct

We aim for a technically rigorous and welcoming collaboration space.

- Treat contributors respectfully. Critique code and ideas, not personal traits.
- Accept good-faith questions and corrections across experience levels.
- Do not harass, threaten, discriminate, disclose private information or spam.
- Do not submit malicious content, stolen work or credentials.
- Ground technical claims in evidence; distinguish proposals from verified work.

The maintainer may request edits, moderate content or restrict participation
to protect contributors. Actions should be proportionate and explain the
behavior at issue where doing so does not disclose private information.

Use an available private GitHub route for conduct concerns. If none is
available, request a private contact without publishing identifying details.
A dedicated moderation contact has not yet been established.
